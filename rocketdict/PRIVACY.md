# Public handoff privacy boundary

This repository is public. RocketDict handoff material must remain strictly project-only.

Do not add:
- personal names/profile information not inherently part of the public repository;
- home/work location or unrelated geographic history;
- account identifiers, contacts, email, phone, credentials, tokens or secrets;
- health/legal/financial/political or other unrelated private conversation context;
- unrelated projects or purchase/history context;
- raw chat transcripts.

Allowed:
- RocketDict source/code;
- public model/corpus URLs and hashes;
- experiment designs/results;
- public GitHub Actions run/artifact identifiers;
- anonymized technical paths only where necessary;
- reproducibility instructions.

The handoff documents were intentionally written without personal user context. A future assistant should preserve this boundary when committing new evidence.
