- The single rejected full replay `34749776816` followed by accepted diagnostic replay `34750071679` is insufficient to authorize run59 because the rejected raw candidate was not retained. However, later evidence materially changes the diagnosis: broad CTranslate2 4.8.2 determinism workflow `34750592651` reproduced the exact historical parity target and selector PASS across AMD and Intel, current/single-thread, `384/512`, fresh processes, and portable DNNL. - Forced MKL CNR (`CT2_USE_MKL=1`, `MKL_CBWR=COMPATIBLE`, fixed one thread, dynamic off, AVX2, packed GEMM off) is a proven deterministic fallback policy from workflow `34751000550`: three AMD generations and both 384/512 produced identical exact-parity raw rank0 and selector PASS. Do **not** make it Product-default merely because it is reproducible; use it only if a later platform/production replay demonstrates a need. CTranslate2 backend selection is process-static after first use, so any future forced-backend policy must be established before backend initialization or isolated in a subprocess rather than mutating environment variables after OPUS has initialized CTranslate2.
- CT2 converted asset bytes are platform/host-class sensitive and must not be conflated with source checkpoint identity. Workflow `34751186058` proved three AMD conversions byte-identical with tree `09d8b2e6…`; a later Intel conversion produced a different tree while translating the arithmetic source identically. Windows Server 2025 conversion produced another tree `3f353941…` and still translated identically. Therefore a release may either distribute a canonical prebuilt asset with its own immutable hash or accept explicitly platform-specific verified asset manifests; it must not assume a source checkpoint deterministically converts to one universal CT2 byte tree.
- One completed Windows reproducibility replica in workflow `34751346680` proved both ordinary and forced-MKL-CNR raw inference exact-parity/selector-PASS on Windows Server 2025 for 384 and 512. Cross-Windows completion must still be confirmed before calling the portability matrix closed.
- Promotion/diagnostic evidence must retain rejected raw target text/tokens and bind CTranslate2 version, generation parameters, asset manifest/tree identity, execution policy, and host/platform class. A fail-closed rejection without enough forensic data is acceptable operationally but not sufficient as research evidence for changing runtime contracts.
